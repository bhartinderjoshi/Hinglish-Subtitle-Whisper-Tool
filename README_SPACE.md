# 🎬 Whisper Hindi-to-Hinglish Subtitle Generator

Generate accurate SRT subtitles from video and audio files using AI-powered speech recognition.

## Features

- 🎯 **Oriserve Models**: Hindi/Hinglish optimized (Apex, Prime, Swift)
- 🔧 **Custom Models**: Support any HuggingFace Whisper model
- 🎬 **Video Preview**: Real-time subtitle preview
- ✏️ **Live Editor**: Edit subtitles with timing
- 🎨 **Subtitle Overlay**: See subtitles on video
- 📥 **SRT Export**: Download edited subtitles

## Supported Formats

**Video:** MP4, AVI, MOV, MKV, WEBM, FLV, WMV, M4V
**Audio:** WAV, MP3, OGG, FLAC, M4A, AAC, WV, WMA, OPUS

## Usage

1. Upload your video/audio file
2. Select AI model (Apex recommended for Hindi/Hinglish)
3. Adjust settings (VAD threshold, max words, etc.)
4. Generate subtitles
5. Preview and edit
6. Download SRT file
