===============================================
HOW TO ENABLE GPU ACCELERATION
===============================================

OPTION 1: Automatic Installation (Recommended)
----------------------------------------------
1. Double-click: install_cuda_pytorch.bat
2. Wait for installation (5-10 minutes)
3. Restart the server

OPTION 2: Manual Installation
----------------------------------------------
1. Open Command Prompt or PowerShell
2. Run these commands:

   pip uninstall -y torch torchvision torchaudio
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

3. Restart the server

===============================================
TROUBLESHOOTING
===============================================

Problem: "CUDA Available: False" after installation
Solution:
1. Restart your computer
2. Check NVIDIA drivers are up to date
3. Run: nvidia-smi (should show GPU info)
4. Reinstall PyTorch with CUDA

Problem: "Out of memory" error
Solution:
1. Close other GPU-using applications
2. Use Swift model instead of Apex/Prime
3. Process shorter videos
4. Restart computer to free GPU memory

Problem: Server still using CPU
Solution:
1. Stop the server (Ctrl+C)
2. Run: python check_gpu.py
3. Verify CUDA is available
4. Restart server
